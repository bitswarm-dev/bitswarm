## BitSwarm 1.1.0

The product is now written **BitSwarm**. This release changes the name in the app, the docs and the images, and in the `User-Agent` BitSwarm sends. There are no database or settings changes, and nothing you saved needs to be edited.

### What changed

- **The name.** The dashboard (logo, page title, sign-in, legal notice, hooks warning, settings, errors), server messages and the execution log, the README and every doc, the issue templates and the release title all say BitSwarm ([#18](https://github.com/bitswarm-dev/bitswarm/pull/18)).
- **User-Agent.** Requests BitSwarm makes now send `User-Agent: BitSwarm/<version>`: hook requests, scheduled searches, the update check and torrent file downloads. The client name shown to BitTorrent peers changed the same way ([#19](https://github.com/bitswarm-dev/bitswarm/pull/19)).
- **Images.** The screenshots, the recipe screenshots and the social preview card were retaken or rebuilt with the new name ([#19](https://github.com/bitswarm-dev/bitswarm/pull/19)).

### What stays the same

The Docker images (`dockerkeithics/bitswarm-server` and `dockerkeithics/bitswarm-web`), the repository, the Go module, the `SWARM_*` environment variables, saved settings, hooks, schedules, rename presets and backups keep their names and formats. Old backups import as before.

### Upgrading

- **Docker:** `docker compose pull && docker compose up -d`.
- **If something matches the User-Agent.** A receiver, proxy rule or tracker filter that matches `Bitswarm/` **case-sensitively** will stop matching. Change it to `BitSwarm/`, or match without regard to case. Header names are case-insensitive, but values usually are not.
- Nothing else needs to change.
