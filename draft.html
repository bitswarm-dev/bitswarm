Use Swarm legally

Swarm is a general-purpose BitTorrent client. It isn’t built for piracy, and it doesn’t provide, host or index any content.

Only download and share files you have the right to, such as open-source software, public-domain works and content released under free licenses. Copyright laws differ by country, and you’re responsible for following the laws where you live.

The author of Swarm isn’t liable for how you use it, or for any content you download or share with it.

Hooks are for advanced users

Hooks act on their own every time an event happens, with no confirmation:

  • Commands run on the machine where Swarm runs, with Swarm’s permissions. A wrong command can delete or overwrite files.
  • API calls send torrent names, folders and other details to the address you enter.
  • A hook that fires often can flood a server or start many programs at once.

Only set up hooks you understand, and test them on unimportant data first.

You use hooks at your own risk. Swarm and its developers aren’t responsible for any damage, data loss or other harm caused by hooks you create or run.
